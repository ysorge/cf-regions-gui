# Security policy

Please report security issues privately through [GitHub security
advisories][advisory]. Do not include sensitive details in a public issue.

`cf-regions-gui` is an offline desktop application: it does not start a local
server or request remote map resources. Security reports may nevertheless
concern local file handling, rendering, dependencies, or packaged resources.

[advisory]: https://github.com/ysorge/cf-regions-gui/security/advisories/new
